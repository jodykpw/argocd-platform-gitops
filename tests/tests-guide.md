# tests: checks you run by hand after a change

- Not watched by Argo CD. Each script creates its own temporary objects and removes them again.
- One script per app or area; the order to run them on a fresh cluster is `docs/fresh-install-order.md`.
- Options: `SC=<storageclass>` (Longhorn test, default `longhorn`), `KEEP=1` (do not clean up), `NS`, `IMG`.
- A good run ends with `passed: N   failed: 0` and a line such as `LONGHORN BASIC CHECK: OK`; the exit code is 0 on success.
